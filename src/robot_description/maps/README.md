# `src/robot_description/maps/`

This directory contains the 2D occupancy grid map files for the `large_warehouse` environment, used by Nav2 and AMCL for global path planning and robot localization.

---

## Files

### 1. `large_warehouse.yaml`
- **What it does**: Metadata specification for the warehouse occupancy grid map.
  - `image`: `large_warehouse.pgm`
  - `resolution`: `0.05` meters per pixel
  - `origin`: `[-8.0, -8.0, 0.0]` (world frame offset of bottom-left pixel)
  - `occupied_thresh`: `0.65`
  - `free_thresh`: `0.25`
  - `negate`: `0`
- **Requirement**: Ingested by `nav2_map_server` to load the map into the ROS 2 `/map` topic and costmaps.

---

### 2. `large_warehouse.pgm`
- **What it does**:
  - High-resolution grayscale raster image representing warehouse occupancy.
  - Generated by computing exact bounding boxes for all 17 storage shelves and perimeter walls, rasterizing them as 100% solid occupied pixels (`0` = black) and aisles as free space (`254` = white).
  - Unlike raw raycast maps that have hollow shelf interiors, solid rasterization guarantees that the Navfn global planner cannot plan shortcut paths through shelves.
- **Requirement**: Mandatory for AMCL particle filtering, scan matching, and Nav2 global path calculation.\n
